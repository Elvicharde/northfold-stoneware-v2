# Northfold Stoneware

A minimalist, responsive product website showcasing Northfold's flagship stoneware mug in three glazes: Oat, Slate, and Moss. Each glaze features four product views: sunlight, front, interior, and lifestyle.

The product preview and thumbnail switching are implemented with native HTML and CSS, avoiding JavaScript for an interaction the browser can handle natively.

The quantity selector remains static because implementing functional controls without JavaScript would either compromise the design or introduce nonfunctional buttons. For a static showcase, preserving the visual experience is preferable to adding unnecessary functionality.

**Live site:** [Northfold Stoneware](https://elvicharde.github.io/northfold-stoneware/)
